🗒️ ERP System

NotaCore ERP

Production-ready ERP PWA with multi-tenant architecture. Built from real warehouse operational experience, coded entirely on Android via Termux.

🐙 View Source Code ← Back to Portfolio

Core Modules

📊
Real-Time Dashboard
Live metrics: total penjualan, laba bersih, total transaksi, and stok menipis alerts.
🛒
Point of Sale (POS)
Quick-product grid, cart system, jual/keluar/riwayat tracking. Designed for fast checkout.
📦
Inventory Management
CRUD produk, variant pricing, warehouse location tracking, and stock adjustment via journal entries.
📒
Full Accounting
Jurnal umum, laporan keuangan, neraca, and chart of accounts. Accounting best practices built-in.
🏢
Multi-Tenant
Manage multiple businesses from one account. Role-based access control (owner, admin, staff).
🌙
Dark Mode
Persistent dark/light theme toggle. Optimized for mobile screens and warehouse lighting.
