Who I Am

About Me

Not a typical developer path. And that's the point.

I started in warehouse operations — managing inventory, processing inbound/outbound goods, and maintaining stock accuracy. For years, I lived the pain of manual tracking, paper logs, and spreadsheets that never quite worked.

That frustration became fuel. I learned Excel Power Query and data analysis to automate reports. Then Python to build tools. Then web technologies to create systems that others could actually use.

Today, I build ERP, WMS, and POS systems — not from a coding bootcamp, but from real operational needs I experienced firsthand. Every feature I code solves a problem I've actually faced on the warehouse floor.

Built with AI-assisted development, guided by operational knowledge, shipped from an Android phone via Termux. No laptop. No excuses.
