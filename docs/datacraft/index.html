Core Features

📁
Multi-Format Load
CSV, JSON, GeoJSON, Excel, TSV, JSONL, Parquet — all in one tool.
🔍
Auto Detect
Automatic pattern detection for format inconsistencies across files.
🧹
Data Cleaning
Transformasi berbasis pattern dengan preview before & after changes.
🏷️
Bulk Rename
Rename kolom dengan referensi antar file. Bulk operation support.
🔗
Merge Multi-File
Sequential merge "(1 + 2) + 3" dengan outer join support.
📤
Multi-Format Output
Export ke CSV, TSV, JSON, JSONL, XLSX, GeoJSON, Parquet.

Two Modes

⚡
Power Mode
Full control over every step. Advanced options, custom transformations, and Parquet output support. For power users who know exactly what they need.
Available (Beta)
🚀
Basic Mode
Guided workflow with minimal input. Quick cleaning and merge for common scenarios. Get results fast without complex configuration.
